# XENCE website renewal (proposal)

Static build of the renewal proposal (JA at `/`, EN at `/en/`).

- `index.html`, `en/` – pages (Preact + htm, no build step)
- `assets/` – images and videos
- `src/` – generator (`gen.py`, `template.html`) and `convert.py` that turns the design-canvas files into this static site

Pages carry `noindex` until the content is approved.

## Updates (2026-11-19)

- **Hosting**: Cloudflare Pages (account of xencegroup.com), auto-deployed from this repo's `main`. No build step; output directory is the repo root.
- **Assets are cached for a year** (`_headers`). When replacing an image or video, save it under a **new file name** (e.g. `w_reddot_2026.png`) and update the reference; overwriting the same name leaves visitors on the old file.
- **News** is read in the browser from the Google Sheet "XENCE ウェブサイト ニュース管理" (tab `news`, ID in `lib/news.js`). Adding a row there updates the top page and `/news/` without a redeploy. The 14 articles migrated from STUDIO keep their bodies in `lib/news-archive.js` (used when the sheet row has no body); old URLs `/news/<id>` redirect to `/news/?id=<id>` via `_redirects`. A row with a body gets an article page at `/news/?id=<ID>`; otherwise it links to the external URL. `lib/news.js` holds a fallback list used if the sheet can't be reached.
- **Contact** form at `/contact/` (and `/en/contact/`) posts to the Google Apps Script web app "XENCE Web 問い合わせ受付" (URL in `src/pages.py`), which appends to the sheet "XENCE ウェブサイト 問い合わせ" and emails info@xencegroup.com. `?type=build|resource|partner|invest|other` preselects the topic.
- `/contact/`, `/news/` and their EN versions are generated by `src/pages.py`. The hero marquee was removed and the news/contact parts of `app.js` / `en/app.js` were edited directly, so `app.js` is the source of truth for those sections (`src/gen.py` is out of date there).
